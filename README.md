# Lumo Gestão

Plataforma de gestão de RH com painel web para gestores e aplicativo mobile para colaboradores.

## Visão geral

O projeto centraliza rotinas de RH como controle de ponto, jornada, férias, documentos, comunicados e informações do colaborador.

## Módulos

- Painel web administrativo
- Aplicativo mobile para colaboradores

## Funcionalidades

- Gestão de colaboradores
- Registro e histórico de ponto
- Validação de localização no ponto
- Captura de selfie no aplicativo
- Controle de jornada e banco de horas
- Solicitações de férias
- Comunicados e notificações
- Documentos do colaborador
- Perfil e autenticação
- Indicadores e visualização de dados
