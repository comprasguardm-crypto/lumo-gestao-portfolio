# Lumo Design System

A identidade visual oficial do Lumo Gestão usa verde profundo como base e turquesa/verde vivo como destaque.

## Paleta canônica

| Token | Hex | Uso |
| --- | --- | --- |
| Ink Deep | `#031F1A` | fundos premium, login, marca |
| Ink | `#062B24` | texto principal, botões, navegação |
| Ink Soft | `#0B3A31` | hover, estados secundários |
| Turquoise | `#20E3A2` | destaque principal, seleção, foco |
| Mint | `#6EF2C2` | gradientes e destaques suaves |
| Lime | `#8BFF6A` | gradiente da marca |
| Background | `#F4FBF8` | fundo geral |
| Surface | `#FFFFFF` | cards e campos |
| Surface Soft | `#EAF7F2` | áreas secundárias |
| Border | `#D9E8E2` | divisórias e contornos |
| Text Muted | `#61736D` | textos secundários |
| Success | `#16A36A` | sucesso |
| Warning | `#F59E0B` | alerta |
| Danger | `#DC3C4D` | erro |
| Info | `#0EA5A8` | informação |

## Regras

- Não adicionar novas cores de marca diretamente em componentes.
- No Web, usar os tokens de `globals.css` via Tailwind.
- No Mobile, usar sempre `LumoColors`.
- Vermelho, amarelo e verde de estado devem ficar restritos a feedback semântico.
- O turquesa é o principal destaque interativo.
- O verde profundo é a base institucional da marca.
